- 2026-09-11 — Bug fix (found via real-vault testing, not the original self-check): `MirrorToSourceNote`'s exact-text match assumed Tasks.md and its source note carry identical description text once citations are stripped. Confirmed false — Tasks.md entries are routinely condensed summaries of the fuller source-note line. Replaced with a content-word-overlap match (stopword-filtered, requires a clear unambiguous winner above a minimum overlap; anything less confident warns and leaves the source note alone rather than risk editing the wrong line). Chose this over a stable per-task marker id (the more exact fix) because a marker scheme means rewriting every task line across the user's actual vault notes — too big a call to make unilaterally. Self-check now includes a condensed-vs-fuller regression case plus a no-match-degrades-safely case.
- 2026-09-11 — Read-only full-vault validation: `tasklens list` (no filters) against the real `Tasks.md` parses all 36 task lines with zero warnings (matches a plain grep count). No write ops run against the real vault by design — that stays the user's call, not something either build agent decided unilaterally.
